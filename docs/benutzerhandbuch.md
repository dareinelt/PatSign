# Benutzerhandbuch

1. Anmelden
2. PDF manuell hochladen oder Importordner prüfen
3. Analyse ausführen
4. Patientenprüfung (Fallnummer, Name, Geburtsdatum)
5. Signatur inkl. optionaler E-Mail-Zustimmung erfassen
6. Abschlussseite erzeugen und Gesamt-PDF speichern

## Patientenmappe an ein iPad senden

1. Im Dashboard beim wartenden Patienten „An Gerät senden“ wählen.
2. Freies Gerät auswählen (nur freie Geräte sind wählbar) und bestätigen.
3. Das iPad wechselt automatisch vom Wartebildschirm in den Signaturassistenten.
4. Nach Abschluss der Unterschrift wird das Gerät automatisch freigegeben und zeigt wieder „Bitte warten…“.

## iPad einrichten (Kioskmodus)

1. Anwendung auf dem iPad öffnen – Tablets werden automatisch erkannt und zur Geräteregistrierung geleitet.
2. Eindeutigen Gerätenamen vergeben (z. B. „Anmeldung 1“, „OP 1“).
3. Danach arbeitet das Gerät ausschließlich im Kioskmodus: keine Patientensuche, keine Navigation – nur zugewiesene Mappen.
